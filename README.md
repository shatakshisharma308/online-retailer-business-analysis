# Online Retailer Business Analysis

## Project Overview
This project analyses online retail transaction data to understand customer purchasing behaviour, product performance and revenue trends. The aim is to identify useful business insights that can support sales performance, customer segmentation and decision-making.

The analysis was completed using Python, with a focus on data cleaning, exploratory data analysis, revenue analysis and RFM preparation.

## Business Problem
Online retailers generate large volumes of transaction data, but this data needs to be cleaned and analysed before it can support useful business decisions.

This project focuses on answering questions such as:
- Which products sell the most?
- Which countries generate the highest revenue?
- How do customers differ in terms of recency, frequency and monetary value?
- How can transaction data support future customer segmentation?

## Dataset
The dataset contains online retail transactions from a UK-based retailer.

Key fields include:
- Invoice number
- Stock code
- Product description
- Quantity
- Invoice date
- Unit price
- Customer ID
- Country

Initial dataset size:
- 317,307 rows
- 8 columns

After cleaning:
- 243,887 valid transaction rows
- 3,295 unique customers
- 11,794 invoices
- 3,745 products
- 33 countries

## Work Performed

### 1. Data Loading and Inspection
- Imported the online retail dataset using Pandas
- Reviewed dataset structure, column names, data types and missing values
- Checked the shape of the dataset before cleaning

### 2. Data Cleaning
- Removed rows with missing values
- Removed cancelled transactions where invoice numbers started with `C`
- Converted invoice dates into datetime format
- Created a revenue column using quantity and price

### 3. Exploratory Data Analysis
- Analysed top-selling products by quantity sold
- Reviewed revenue generated by country
- Identified key product and market trends

### 4. Revenue Analysis
- Calculated total revenue from valid transactions
- Grouped revenue by country to identify top-performing markets

### 5. RFM Preparation
Created an RFM table to support future customer segmentation:
- Recency: days since last purchase
- Frequency: number of invoices per customer
- Monetary: total customer spend

## Key Findings

- The cleaned dataset contained 243,887 valid transactions.
- The analysis covered 3,295 unique customers across 33 countries.
- Total revenue from valid transactions was approximately £5.38 million.
- The United Kingdom generated the highest revenue at approximately £4.51 million.
- The top-selling product by quantity was `PACK OF 72 RETRO SPOT CAKE CASES`, with 39,767 units sold.
- Other high-volume products included `WHITE HANGING HEART T-LIGHT HOLDER` and `WORLD WAR 2 GLIDERS ASSTD DESIGNS`.
- RFM analysis showed differences in customer recency, purchase frequency and monetary value, providing a foundation for customer segmentation.

## Business Recommendations
- Focus marketing and retention efforts on high-value customers identified through RFM analysis.
- Use top-selling product insights to support stock planning and promotional campaigns.
- Review high-revenue countries to prioritise market-specific strategies.
- Use RFM scores as a foundation for future customer segmentation and personalised campaigns.
